Domain Name RelationshipTypeEnum
Example Value Reference
Domain Type Enumeration
Data Type nvarchar(max)
Value Description
Reference The primary entity contains a reference to the secondary entity
ParentChild Multiple instances of the secondary entity are nested within the primary entity
NestedObject Nesting is used to fully describe the single instance of the secondary entity which is referenced by the primary entity
DescriptiveReference Nesting is used to partially describe the single instance of the secondary entity which is referenced by the primary entity. The nested item is a "reference" which holds more than just an identifier - it also contains some additional information about the referenced object, with the aim of reducing the need for the secondary entity to be fetched separately.
Subtype The secondary entity extends the primary entity, providing additional information that is relevant to a particular of that entity.
UniqueChild A single instance of the secondary entity is nested within the primary entity
PassThrough The relationship forms part of the path between two entities, but it is not exposed within hierarchical renderings: it is "collapsed" or "passed-through") .
