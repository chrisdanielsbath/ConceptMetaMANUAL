Domain Type Enumeration
Data Type nvarchar(max)
Value Description
UniqueContainer The parent concept forms part of the unique identifier for the child concept, and acts as the unique container when the model is expressed in a hierarchical structure
Identifying The parent concept forms part of the unique identifier for the child concept, but does not act as the unique container
Descriptive The parent concept provides non-identifying, descriptive detail about the child concept
